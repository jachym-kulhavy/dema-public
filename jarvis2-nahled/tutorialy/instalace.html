Instalace od nuly

Claude Code, Python 3.12, přístup na GitHub a instalace.bat.

1Claude Code a předplatné

Potřebuješ Windows 10/11 a předplatné Claude (Pro nebo vyšší), které platíš přímo Anthropicu. Claude Code nainstaluješ podle oficiálního návodu.

instalace.bat
Chybi Claude Code. Nainstaluj ho podle https://claude.com/product/claude-code a spust tenhle soubor znovu.

2Python 3.12

Stáhni Python 3.12 a při instalaci zaškrtni „Add python.exe to PATH“. Novější verze nemusí zvládnout přepis řeči z videí.

instalace.bat
Chybi Python (potrebuje ho bezpecnostni pojistka Jarvise). Stahni ho z https://www.python.org/downloads/a pri instalaci zaskrtni "Add python.exe to PATH". Pak spust tenhle soubor znovu.Upozorneni: Jarvis je vyzkouseny s Pythonem 3.12. S jinou verzi nemusi fungovat prepis reci z videi.

3Účet na GitHubu

Založ si účet na GitHubu (zdarma). Po zaplacení ti na něj přijde pozvánka k Jarvisovi, přijmi ji na github.com. Při první instalaci se otevře okno „přihlásit se ke GitHubu“, přihlas se tím účtem.

instalace.bat
Nemas pristup. Prijmi pozvanku od Jarvise na github.com (prijde ti po zaplaceni e-mailem),prihlas se tim GitHub uctem a spust instalace.bat znovu.

4Spusť instalace.bat

Dvakrát klikni na instalace.bat. Zkontroluje, že máš všechno, a když nejsi přihlášený do Claude, otevře přihlášení. Nainstaluje se jen do složky Jarvis ve tvé uživatelské složce.

instalace.bat
instalace.bat
Prihlas se do sveho Claude uctu (otevre se prohlizec)...Instaluji Jarvise do slozky C:\Users\<ty>\Jarvis ...Overuji pristup k Jarvisovi na GitHubu (muze se otevrit prihlaseni ke GitHubu)...Hotovo. Ted se te Jarvis par otazkami zepta, co delas, a nastavi se.

5Když se něco nepovede

Skript napíše, co opravit, a nabídne spuštění znovu.

instalace.bat
Nepodarilo se stahnout Jarvise. Mas pristup k repozitari a internet?Instalace zakladu selhala.Instalace se nedokoncila. Oprav to, co je napsane vyse, a spust instalace.bat znovu.

6Co dál

Po instalaci se hned spustí onboarding. Jarvis spustíš a připojíš k mobilu podle prvního spuštění.
