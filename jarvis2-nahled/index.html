Jak to funguje

01

Instalace

Spustíš instalace.bat. Stačí Windows, Python a Claude Code s tvým účtem.

02

Onboarding

30–45 minut otázek po oblastech, jedna zpráva = jedna otázka. Dá se pauznout a navázat.

03

Jen tvoje moduly

Podle odpovědí doporučí moduly a nainstaluje jen ty, které vybereš.

04

Z mobilu

Dvojklik na Jarvis.bat a v Claude appce vybereš session „Jarvis“.

Moduly

Základ

Onboarding, paměť v souborech, spouštěč pro mobil a pojistka: bez tvého OK nic neodejde.

Scout

Pošleš odkaz na nástroj nebo reel, otestuje ho v izolované složce, doladí a vrátí verdikt.

Oslovení

Research podniků, osobní drafty e-mailů a jednoduché CRM. Odesílá jen po schválení.

Bloky

Práce na pozadí podle plánu, hlídá limity předplatného, ranní report.

Vzhled (mod)

Mod přebarví Claude appku na námořnickou modř s tyrkysovým akcentem, přidá stavový řádek, uvítání a povahu Jarvise. Takhle vypadá start v terminálu:

PS C:\Users\ty\Jarvis> .\Jarvis.bat
✓ Claude Code nalezen, přihlášení OK
✓ Aktualizace: zaklad, scout, mod jsou aktuální
✓ Remote Control běží (session „Jarvis“)
i Otevři Claude appku na mobilu → Code → Jarvis
